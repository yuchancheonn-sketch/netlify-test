# 브랜드 이미지 폴더

이 폴더에 넣어야 하는 파일들입니다. **파일 이름을 정확히 맞춰 주세요.**

## `dosan.jpg` — 로그인 화면 배경

도산 안창호 선생 사진입니다. 로그인 화면 배경으로 쓰입니다.

- 파일 이름: **`dosan.jpg`** (소문자, 확장자 `.jpg`)
- 세로로 긴 사진이 좋습니다. (인물이 화면 위쪽 2/3 지점에 오도록 잘립니다)
- 권장 크기: 긴 변 1200~1600px, 500KB 이하
  더 크면 첫 화면이 느리게 뜹니다.

파일이 없어도 앱은 정상 동작합니다. 배경 없이 따뜻한 오프화이트만 보입니다.

## `dosan-academy.png` — 로딩 화면 로고

도산아카데미 심볼(남색 새 + 둘레의 DOSAN ACADEMY 글씨)입니다.
앱을 열 때 잠깐 뜨는 흰 화면 한가운데에 놓입니다.

- 파일 이름: **`dosan-academy.png`** (소문자, 확장자 `.png`)
- **배경이 투명한 PNG**를 권합니다. 흰 바탕 위에 놓이므로 흰 배경이 딸린
  파일도 티는 안 나지만, 투명한 쪽이 나중에 다른 곳에 쓰기 좋습니다.
- 권장 크기: 가로 300~600px. 화면에는 150px로 줄여 그리므로 그 두 배면
  고해상도 화면에서도 또렷합니다. 100KB 이하면 충분합니다.
- 가로세로 비율은 아무래도 괜찮습니다. 폭만 맞추고 높이는 비율대로 따라옵니다.

파일이 없으면 로고 자리에 "도산아카데미"라고 남색 글씨로 대신 나옵니다.
파일을 넣으면 코드를 고치지 않아도 바로 로고로 바뀝니다.

## `goose.png` — 앱 아이콘 배경 무늬 (기러기)

앱 아이콘의 주황 바탕 위에 흰색 반투명으로 은은하게 깔리는 기러기 실루엣입니다.

- 파일 이름: **`goose.png`** (`.jpg` / `.webp` 도 됩니다)
- **배경이 투명한 PNG가 가장 깔끔합니다.** 투명도를 그대로 써서 정확히 잘립니다.
- 투명 배경이 아니면 밝기 차이로 모양을 잡아냅니다.
  하늘처럼 배경이 단순한 사진일수록 잘 따집니다.

파일을 바꾼 뒤에는 아이콘을 다시 구워야 합니다.

```bash
npm run icons
```

실루엣을 제대로 못 따내면(화면의 1% 미만이거나 70% 초과) 경고를 띄우고
예전 물결 무늬로 되돌아가므로, 이상한 아이콘이 만들어지지는 않습니다.

## `logo.png` — 애기애타 서예 로고 (선택)

`愛己愛他` 서예 로고 원본입니다. 아직 화면에 연결하지 않았습니다.
넣어두시면 로그인 화면 상단에 쓰도록 이어드립니다.
