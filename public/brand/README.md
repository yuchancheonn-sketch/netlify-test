# 브랜드 이미지 폴더

이 폴더에 넣어야 하는 파일들입니다. **파일 이름을 정확히 맞춰 주세요.**

## `dosan.jpg` — 로그인 화면 배경

도산 안창호 선생 사진입니다. 로그인 화면 배경으로 쓰입니다.

- 파일 이름: **`dosan.jpg`** (소문자, 확장자 `.jpg`)
- 세로로 긴 사진이 좋습니다. (인물이 화면 위쪽 2/3 지점에 오도록 잘립니다)
- 권장 크기: 긴 변 1200~1600px, 500KB 이하
  더 크면 첫 화면이 느리게 뜹니다.

파일이 없어도 앱은 정상 동작합니다. 배경 없이 따뜻한 오프화이트만 보입니다.

## `dosan-portrait.png` — 홈 "오늘의 도산" 카드의 초상

흰 바탕에 검은 점으로 찍은 판화풍 도산 선생 초상입니다.
홈 화면 "오늘의 도산" 카드의 오른쪽 아래, 이름 옆에 놓입니다.

- 파일 이름: **`dosan-portrait.png`** (소문자, 확장자 `.png`)
- **배경이 흰색이거나 투명해야 합니다.** 흰 카드 위에 곱하기로 겹쳐 얹기
  때문에(mix-blend-multiply) 흰 배경은 흔적 없이 사라집니다. 배경이 어두운
  사진을 넣으면 카드에 검은 네모가 박힙니다.
  (같은 폴더의 `dosan.jpg`는 배경이 어두운 컬러 사진이라 여기 쓸 수 없습니다.)
- 권장 크기: 세로 250~400px. 화면에는 높이 84px로 줄여 그리므로 그 서너 배면
  고해상도 화면에서도 또렷합니다. 200KB 이하면 충분합니다.
- 가로세로 비율은 아무래도 괜찮습니다. 높이만 맞추고 너비는 비율대로 따라옵니다.

파일이 없으면 초상 자리를 조용히 비웁니다(카드는 예전 모습 그대로).
파일을 넣으면 코드를 고치지 않아도 바로 나타납니다.

## `goose.png` — 도산아카데미 로고 (두 곳에서 씁니다)

도산아카데미 심볼입니다. 새를 가운데 두고 둘레에 `DOSAN ACADEMY`,
아래에 `SINCE 1989`가 둘러선 원형 마크입니다.

쓰이는 곳이 둘입니다.

1. **로딩 화면** — 앱을 열 때 잠깐 뜨는 흰 화면 한가운데에 그대로 놓입니다.
   (`components/StageGate.tsx`의 SplashScreen)
2. **앱 아이콘 배경 무늬** — 여기서 새 실루엣만 따내어, 아이콘의 주황 바탕
   위에 흰색 반투명으로 은은하게 깝니다.

파일 이름이 로고 같지 않은 것은 2번 용도로 먼저 들어온 파일이기 때문입니다.
같은 그림을 두 벌 두면 언젠가 한쪽만 바뀌므로 그대로 함께 씁니다.

- 파일 이름: **`goose.png`** (`.jpg` / `.webp` 도 됩니다)
- **배경이 투명한 PNG가 가장 깔끔합니다.** 실루엣을 딸 때 투명도를 그대로
  써서 정확히 잘립니다.
- 투명 배경이 아니면 밝기 차이로 모양을 잡아냅니다.
  하늘처럼 배경이 단순한 사진일수록 잘 따집니다.
- 권장 크기: 가로 600px 이상. 로딩 화면에 150px로 줄여 그리므로
  그 네 배쯤이면 고해상도 화면에서도 또렷합니다. (지금 파일은 700×700)

파일을 바꾼 뒤에는 아이콘을 다시 구워야 합니다.

```bash
npm run icons
```

실루엣을 제대로 못 따내면(화면의 1% 미만이거나 70% 초과) 경고를 띄우고
예전 물결 무늬로 되돌아가므로, 이상한 아이콘이 만들어지지는 않습니다.
