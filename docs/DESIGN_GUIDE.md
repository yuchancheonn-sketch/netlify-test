# 애기애타 앱 디자인·기능 가이드

> 교육 과정 원우(수강생)들만 쓰는 **비공개 커뮤니티 웹앱(PWA)** 을 만들 때 참고할 수 있도록,
> 이 앱의 화면 짜임·색·글자 크기·박스 모양·버튼 동작을 실제 값 그대로 정리한 문서입니다.
> 값은 모두 코드(`src/`)에서 옮겨 왔습니다(2026-09-27 기준). 단위는 CSS px이고, 괄호 안은 Tailwind 클래스입니다.

---

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 무엇 | 한 교육 과정(기수제)의 원우 전용 커뮤니티. 원우 명단, 일정, 투표, 채팅, 자료, 위원회 소식 |
| 누가 | 기수별 원우 수십 명 + 운영진. 대부분 40~60대, 휴대폰으로 사용 |
| 어디서 | 휴대폰 브라우저 → "홈 화면에 추가"한 앱(PWA)이 주 사용처. 카카오톡 인앱 브라우저로도 열림 |
| 디자인 방향 | 당근·카카오톡처럼 **익숙한 국내 앱 문법**. 흰색·옅은 회색 바탕 + 주황 한 가지 강조색. 글씨는 크고 또렷하게 |
| 기술 | Next.js(App Router) + TypeScript + Tailwind CSS v4, Firebase Auth·Firestore, 사진·파일은 Cloudinary, 호스팅은 Firebase App Hosting |

### 디자인 원칙 다섯 가지
1. **강조색은 주황 하나** — 글씨·아이콘·배경 어디든 주황이 필요하면 같은 `#FD5702`.
2. **그림자 대신 1px 회색 테두리** — 글로우(번지는 그림자)는 쓰지 않습니다.
3. **흰 화면 위에는 회색 칸, 회색 화면 위에는 흰 카드** — 바탕과 칸의 명암을 늘 뒤집어 둡니다.
4. **목록은 박스 대신 줄**(채팅·파일·원우·알림) — 카카오톡 대화 목록처럼 흰 바탕에 줄만 세웁니다.
5. **픽셀 단위로 맞춤** — 글씨 위치를 0.25~2px씩 옮겨 가며 눈으로 가운데를 맞췄습니다(9장 참고).

## 2. 색 (디자인 토큰)

색은 "흰색", "회색"이라는 **색 이름이 아니라 역할 이름**으로 씁니다. 그래야 다크 모드에서 값만 갈아끼우면 됩니다.

### 2-1. 밝은 화면

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `brand-500` | `#FD5702` | **유일한 강조색.** 주 버튼, 선택된 탭, D-day, 링크 글씨, 날짜 머리글 |
| `brand-400` | `#FE8243` | (거의 안 씀) |
| `brand-300` | `#FEA171` | 입력칸 눌렀을 때 둘레(85%), 빈 화면 아이콘 |
| `brand-200` | `#FEC2A4` | 눌리지 않는(disabled) 주황 버튼 바탕 |
| `brand-100` | `#FFE1D1` | 연한 주황 칸 눌린 상태 |
| `brand-50` | `#FFF2EB` | 연한 주황 배지·안내 상자 바탕 |
| `canvas` | `#ECECEB` | 페이지 바탕(회색 화면) |
| `surface` | `#FFFFFF` | 카드·시트·흰 화면 바탕 |
| `fill` | `#F5F5F4` | 흰 바탕 위 한 겹 옅은 회색 — 눌린 상태, 남의 말풍선, 채팅 입력칸 |
| `field` | fill과 canvas의 **정확히 중간** | 흰 화면 위 입력칸(프로필·원우 정보) |
| `line` | `#E4E6E9` | 카드 테두리·구분선 1px |
| `ink` | `#1C1917` | 본문·제목 글씨(완전 검정 대신 붉은 기 도는 먹색) |
| `ink-soft` | `#57534E` | 버튼 글씨, 아이콘 |
| `ink-muted` | `#78716C` | 보조 글씨(설명, 시간, 장소) |
| `ink-faint` | `#A8A29E` | 흐린 글씨(예시 문구, 날짜, "선택") |
| `danger` | `#DC2626` | 오류 문구, "필수", 삭제, 새 알림 점 |
| `navy` | `#1B3A6B` | 기관 심볼 색 — 기관 표기에만 아주 제한적으로 |

- 주황은 **어두운 단계(600~900)를 일부러 두지 않았습니다.** 있으면 갈색이 스며듭니다.
- 흰 바탕 위 주황 글씨는 대비 3.2:1이라 접근성 기준(4.5:1)에 못 미칩니다. 읽기 어렵다는 말이 나오면 색을 어둡게 하지 말고 **굵게** 하거나 **주황 바탕 + 흰 글씨**로 뒤집습니다.
- 떠 있는 검은 메뉴(수정·삭제 고르는 작은 판)는 화면 밝기와 상관없이 늘 `#33383E`, 눌린 칸 `#40464D`, 삭제 글씨 `red-400`.
- 카카오 로그인 단추만 카카오 규정색 `#FEE500` + 검정 85% 글씨.

## 3. 글꼴·글자 크기

### 3-1. 글꼴
- 본문: **Noto Sans KR** (400·500·600·700·900 불러옴). 대체 글꼴 Pretendard → Apple SD Gothic Neo.
- 명조: **Noto Serif KR** (400·600). "오늘의 도산" 글귀와 로그인 화면 뜻풀이에만.
- 보기 설정 "큰 글씨"를 켜면 `<html>`에 zoom 1.15를 겁니다.

### 3-2. 글자 크기 표

| 쓰임 | 크기 · 굵기 · 색 |
|---|---|
| 화면 제목(제목 줄) | 22px · 700 · ink · 자간 좁게 |
| 제목 자리 탭 고르개("복습 영상 \| 일정 \| 파일") | 22px · 700, 고른 칸 ink / 나머지 ink-faint, 사이 세로선 2×22px line |
| 밑줄 탭("전체 55명 / 일반 원우 / 대학생 원우") | 17px, 고른 칸 주황 + 아래 2.5px 주황 막대 |
| 카드 제목(홈 박스) | 18px · 700 · ink |
| 달력 달 이름("2026년 9월") | 19px · 700 (숫자가 많아 작아 보여 1px 키움) |
| 목록 이름(채팅 방 이름) | 16px · 700 · ink |
| 원우 이름(원우수첩) | 약 17px · 700 · ink, 회사·직책은 주황 |
| 본문·입력칸 글씨 | 16~17px (**16px 밑으로 내리면 아이폰이 입력칸을 누를 때 화면을 확대**) |
| 폼 칸 이름(라벨) | 15px · 700 (프로필 화면만 17px) |
| 칸 오른쪽 "선택" / "필수" | 12px · 보통 굵기, "선택" ink-muted / "필수" danger |
| 보조 글씨(미리보기·설명) | 13~14px · ink-muted |
| 시간·장소 | 12.5px · 500 · ink-muted, 앞에 시계 14.5px·핀 17px 아이콘 |
| 흐린 글씨(날짜·예시) | 12~13px · ink-faint |
| 하단 탭 이름 | 12.5px · 500 |
| 빈 화면 제목 / 설명 | 15px · 700 · ink-soft / 13px · ink-faint |

- 한글 줄바꿈은 **단어 단위**(`break-keep`)로. 긴 영문·파일명은 `overflow-wrap:anywhere`.
- 한 줄에서 잘리면 끝에 **가운데 높이 "⋯"** 를 붙입니다(채팅 방 이름). CSS 기본 말줄임(아래 "…")은 아이폰에서 다른 글자로 못 바꿔, 칸 폭을 재어 직접 자르는 작은 부품을 씁니다.

## 4. 모서리·테두리·간격

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `rounded-card` | 18px | 홈의 흰 박스들, 위원회 카드 |
| `rounded-3xl` | 16px | 일반 카드 |
| `rounded-2xl` | 14px | 버튼, 입력칸, 칸 안의 작은 상자 |
| `rounded-xl` | 12px | 작은 칸 |
| 시트 윗모서리 | 24px | 아래에서 올라오는 창 |
| 원우수첩 검색칸 | 14px | |
| 원우 사진칸 | 10px | |
| 채팅 목록 사진 | **스쿼클**(네 변이 부푼 둥근 네모, CSS mask) | |
| 알약 | `rounded-full` | 하단 탭바, 설정 줄, 채팅 입력칸 한 줄일 때 |

- **테두리 = 그림자 없이 1px 선.** `box-shadow: 0 0 0 1px var(--color-line)` 로 그립니다. border 대신 box-shadow라서 크기가 1px 커지지 않고 둥근 모서리를 그대로 따라갑니다.
- 화면 좌우 여백: **16px**(`px-4`). 카드 안쪽 여백 16~24px.
- 제목 줄과 본문 첫 칸 사이: 22px(제목 줄 아래 6 + 본문 위 16).
- 홈 박스 사이: 14px. 목록 줄(채팅·파일): 위아래 9px씩.

## 5. 공통 틀

### 5-1. 화면 틀
- 본문 폭 최대 **560px**, 가운데 정렬(태블릿·PC에서도 폰 모양).
- 노치·홈 바 자리(`env(safe-area-inset-*)`)를 늘 비웁니다.
- **바탕 규칙**
  - 회색(`canvas`) 바탕: 홈, 위원회, 설정 — 흰 카드를 얹는 화면.
  - 흰(`surface`) 바탕: 채팅, 자료, 알림, 내 프로필, 첫 가입, 대화방 — 목록·폼 화면.
  - 흰 바탕을 화면 끝까지 칠할 때는 **화면에 붙은 흰 층(`position: fixed; inset: 0; z-index: -10`)** 을 목록 뒤에 깝니다. 본문 상자에 `min-height: 100%`를 주면, 부모 높이가 정해져 있지 않아 목록이 짧을 때 아래로 회색이 드러납니다.

### 5-2. 제목 줄 (PageHeader)
- 화면 맨 위에 붙어 있습니다(`sticky`). 위 여백 6px + 노치, 아래 6px, 좌우 16px.
- 왼쪽: `<` 뒤로가기(36px 동그라미, 아이콘 28px) + 제목 22px 굵게.
- 오른쪽: **종(알림) · 사람(내 프로필) · 톱니(설정)** 세 아이콘. 아이콘 27px, 누르는 자리 40px, 서로 6px 겹치게 붙임.
- 종 위의 새 알림 점: 지름 7px 빨강, 종의 오른쪽 위(위 9.5px·오른쪽 9px).
- 바탕은 그 화면 바탕과 같은 색(`tone="canvas|surface"`).

### 5-3. 하단 탭바 (떠 있는 알약)
- 탭 다섯 개: **홈 · 원우 · 위원회 · 채팅 · 자료**.
- 모양: 흰 알약(`rounded-full`) + 1px 회색 테두리, 좌우 20px 띄워 화면 아래에서 `max(12px, 홈바−4px)` 위에 떠 있음. 최대 폭 520px.
- 칸: 아이콘 27px + 이름 12.5px, 위 6px·아래 10px 여백.
- 고른 탭: 아이콘이 **채워진 모양 + 주황**, 이름 주황, 칸 뒤에 먹색 7% 옅은 알약이 깔림. 나머지는 선 아이콘 + 먹색.
- 채팅 탭: 안 읽은 메시지가 있으면 아이콘 오른쪽 위에 7px 빨간 점.
- 알약 아래로 지나가는 내용은 살짝 흐리게(backdrop-blur 7px, 아래로 갈수록 짙게).
- 본문 아래 끝에는 알약 높이만큼 여백(82px + 홈바)을 둬 마지막 줄이 가리지 않게 합니다.
- 대화방 안에서는 탭바를 감춥니다.

### 5-4. 아래에서 올라오는 창 (시트)
- 화면을 `ink` 40% 막으로 덮고, 흰 판이 아래에서 올라옴(`animate-sheet-up`).
- 판: 윗모서리 24px, 좌우 24px 여백, 위 12px, 아래 20px + 홈바. 최대 폭 480px. 큰 화면에서는 가운데 뜨는 창(모서리 24px).
- 맨 위 손잡이: 40×4~6px `line` 알약 — **끌어내리면 닫힘.** 바깥 막을 눌러도 닫힘.
- 시트가 떠 있는 동안 뒤 화면 스크롤을 잠급니다.
- 아래 단추 한 줄: 왼쪽 흰 "취소"(1px 테두리) + 오른쪽 주황 주 버튼(넓게).

### 5-5. 확인 창
- 화면 가운데 흰 상자(최대 320px, 모서리 16px), 제목 17px 굵게("진짜 삭제하시겠어요?") + 설명 14px.
- 아래 두 단추 같은 폭: 회색(`fill`) "취소" / 빨강(`danger`) "삭제". 삭제 중엔 스피너.
- 브라우저 기본 `confirm()`은 쓰지 않습니다(아이폰 홈 화면 앱에서 주소가 찍힌 투박한 창이 뜸).

### 5-6. 작은 메뉴 (⋯ 누르면 뜨는 것)
- 검은 판 `#33383E`, 모서리 12px, 칸마다 13px 굵은 흰 글씨, 칸 사이 흰색 15% 1px 선. 되돌릴 수 없는 칸만 빨강(`red-400`).
- 바깥 아무 데나 누르면 닫힘(투명 덮개). 화면을 어둡게 하지 않습니다.

## 6. 공용 부품

### 6-1. 주 버튼 (PrimaryButton)
주황 바탕 + 흰 굵은 글씨, 모서리 14px, 폭 가득, 누르면 0.99배로 살짝 줄어듦. 로딩 중엔 스피너, 비활성은 `brand-200`.

| 크기 | 위아래 여백 · 글씨 | 높이 | 쓰는 곳 |
|---|---|---|---|
| md | 16px · 16px | 약 56px | 화면 아래 큰 버튼 |
| field | 13px · 16px | 약 50px | 폼 "저장하기", 로그인 단추 |
| compact | 8px · 16px | 약 40px | 카드 안 버튼(퀴즈 "정답 제출하기") |
| sm | 10px · 15px | 약 44px | 시트 아래 "취소 \| 등록하기" 줄 |

### 6-2. 흰 보조 버튼
흰 바탕 + 1px `line` 테두리, 같은 높이(테두리 1px만큼 여백을 1px 줄임). 예: 구글·휴대폰 로그인.

### 6-3. 입력칸
| 자리 | 모양 |
|---|---|
| 흰 화면 위(프로필·일정 등록·투표 만들기) | **회색 칸**(`field` 또는 `canvas`), 테두리·그림자 없음, 모서리 14px, 높이 약 44px, 글씨 16~17px |
| 누르면 | 칸 둘레에 **주황 3px 반투명 링**(`brand-300` 85%). 진한 실선 테두리는 없음 |
| 채팅 입력칸 | `fill` 바탕, 한 줄일 때 44px 알약 → 쓰는 만큼 늘어나 5줄(140px)까지, 모서리 22px |
| 검색칸(원우수첩) | `canvas` 바탕, 모서리 14px, 높이 약 37px, 오른쪽 끝 돋보기 28px `ink-faint`, 예시 글씨 17.5px `ink-muted` |

- 칸 이름(라벨) 아래 8px 띄워 칸. 칸 사이 24px.
- 칸 오른쪽 위에 12px "선택"(회색) 또는 "필수"(빨강).
- 오류 문구는 칸 바로 아래 13px 빨강. 저장을 누르면 **처음 걸린 칸까지 화면을 올려** 보여줌.
- 드롭다운(선택 상자)은 기본 모양을 걷고 오른쪽에 회색 꺾쇠 그림(20px)을 깔아 입력칸과 똑같이 보이게.
- 입력칸 안 글씨를 1~2px 옮기고 싶으면 위·아래 여백을 나눠서(예: 위 8 · 아래 12) 옮깁니다. 높이는 그대로.

### 6-4. 탭 고르개 (TextTabs)
- **header**: 제목 자리에 22px 글씨로 "A | B | C". 고른 칸만 진하게.
- **underline**: 칸들이 폭을 똑같이 나눠 가짐. 고른 칸 주황 + 아래 2.5px 주황 막대, 목록 위 경계선 1px. 고른 칸에만 인원수("전체 55명").

### 6-5. 빈 화면 · 오류 · 불러오는 중
- 빈 화면: 가운데 정렬, 연주황(`brand-300`) 아이콘 40px → 제목 15px 굵게 → 설명 13px 흐리게. 위아래 56px.
- 오류: 14px 설명 + (있으면) 연주황 알약 "다시 시도".
- 불러오는 중: 진짜 목록과 **같은 짜임의 회색 자리표시**(Skeleton) — 불러온 뒤 줄 자리가 흔들리지 않게.

### 6-6. 떠 있는 추가 버튼 (FAB)
주황 동그라미 56px + 흰 "+" 28px, 오른쪽 22px · 탭바 위(바닥에서 92px + 홈바). 글씨 없이 아이콘만(화면 읽기에는 "파일 올리기").

### 6-7. 배지
알약, 12px 굵게, 위아래 4px·좌우 10px. 주황(`brand-50` 바탕 + 주황 글씨) / 중립(`fill` + `ink-muted`).

## 7. 화면별 구성

### 7-1. 로그인
- 바탕: 인물 사진(위아래가 서서히 사라지는 마스크) + 아래로 갈수록 짙어지는 크림색 막(사진 얼굴 부분만 옅게).
- 위: 과정 이름 18px 굵게 검정 → 앱 이름 44px 굵게.
- 아래(화면 바닥에서 32px + 홈바 위):
  1. **구글 계정으로 로그인** — 흰 단추 + 구글 4색 로고
  2. **카톡으로 로그인** — 카카오 노랑 `#FEE500`
  3. 회색 선 — 가운데 **"또는"** 13px — 회색 선 (먹색 22%)
  4. **휴대폰 번호로 로그인** — 흰 단추 + 폰 아이콘
  5. "로그인 없이 둘러보기" 14px 밑줄 글씨
- 단추 높이 50px, 사이 11px. 글씨만 아이콘보다 1.25px 위로.
- **회원가입 단추는 따로 없습니다.** 처음 보는 계정이면 로그인하는 순간 가입 절차로 이어집니다(로그인과 가입은 속으로 같은 일).
- 휴대폰 번호 로그인은 화면 하나를 통째로 씀: 번호 입력 → 문자 인증번호 6자리.

### 7-2. 가입 흐름
1. 처음 로그인 → **가입 신청**(기수 고르기) → **승인 대기** 화면
2. 운영진이 승인 → **첫 프로필 채우기**(흰 바탕)
   - 위: "가입 승인 완료 🎉" 15px 주황 → 제목 26px 굵게 두 줄 → 40px 띄움
   - 프로필 사진 112px 동그라미 + 오른쪽 아래 주황 카메라 단추 40px(흰 4px 테두리)
   - 칸: 이름·전화번호·기수(**필수**, 빨강) / 생일(연·월·일 한 줄, 폭 1.3:1:1)·구분(두 단추)·회사·직책·원우회 직위·자기소개·소개 영상 링크(**선택**)
   - 라벨 17px, 칸 글씨 17px, 칸 높이 44px
   - "시작하기" 주 버튼(field)
3. 같은 전화번호로 이미 가입한 계정이 있으면 문자 인증 뒤 **그 계정에 합침**(구글·카톡·휴대폰 어느 걸로 들어와도 한 사람 = 한 계정).

- **전화번호 칸**: 쓰는 대로 `010-1234-5678` 모양으로 붙임표가 들어감. 아이폰 자동완성이 주는 `+821012345678`도 `010-…`으로 바꿔 넣음.
- **사진 편집**: 사진을 고르면 흰 화면에 화면 폭 정사각형 틀이 뜸. 한 손가락으로 끌어 옮기고 두 손가락으로 벌려 크게(최대 4배). 틀 안 3등분 기준선, 동그라미 밖은 흐린 막. 위: 동그란 닫기(X) · "사진 편집" · 주황 동그라미 체크. 체크를 누르면 고른 부분만 정사각형으로 잘라 올림.

### 7-3. 홈 (회색 바탕)
위에서부터 흰 박스(모서리 18px, 1px 테두리)가 14px 간격으로 쌓입니다.

1. **다가오는 일정 카드(D-day)**
   - 첫 줄: 주황 **D-7** 21px 굵게 + 회색 날짜 "10.02 금" 15px
   - 그 아래 세로 막대 3px(도산 공식 일정 주황 / 우리 기수 모임 먹색) + 제목 15.5px(두 줄까지) + "🕒 시간 · 📍 장소" 12.5px
   - 오른쪽 꺾쇠. 누르면 일정 원문으로.
2. **한 달 달력**
   - "2026년 9월" 19px + 오른쪽 ‹ › (36px)
   - 요일 12px(일 빨강, 토 ink-muted, 나머지 흐림), 주마다 위에 옅은 선
   - 날짜 숫자 15px, 28px 동그라미 안. 일요일 빨강
   - 일정 있는 날 아래 6px 주황 점. **오늘은 주황 동그라미 + 흰 굵은 숫자**, **고른 날은 먹색 동그라미 + 흰 굵은 숫자**
   - 아래에 고른 날짜 13px 굵게 + 그날 일정 목록(홈 D-day 카드와 같은 막대 모양, 시간·장소는 두 줄)
   - 오른쪽 **+ 단추**(40px 회색 동그라미) → 일정 등록 시트. 일정이 없으면 두 줄 가운데, 있으면 마지막 일정 옆(도산 일정이면 주황 막대 아래끝에 맞춤)
   - 우리 기수 일정 줄 오른쪽 끝 × → 확인 뒤 삭제(올린 사람·운영진만)
   - 맨 아래 "내 폰 캘린더에 연결"(아이폰·구글 캘린더 구독). 한 번 연결한 기기는 감춤
3. **오늘의 OX 퀴즈** — 제목 18px, 문제 17px(앞에 주황 Q 아이콘), 그렇다(파랑 O)/아니다(빨강 X) 두 칸(높이 40px, 테두리 1.5px). 고르면 "정답 제출하기"(compact) → 채점 중 → 전체 화면 해설
4. **투표·의견** 카드 — 진행 중인 투표. 무기명
5. **바로가기** — 흰 박스 하나에 2열: 투표 만들기 · 의견 모으기 · 역대 투표(그림 아이콘 28px + 15px 글씨)
6. **오늘의 도산** — 명조 18px, 줄 간격 1.8
7. 맨 아래 기관 정보 — "이용약관 | **개인정보처리방침**"(12px, 세로선 사이 6px) + 접히는 "기관 정보 ∨" + 저작권

- **투표 만들기 시트**: 누구에게(우리 기수만 / 전체 기수 — 알약 고르개), 무엇을 물어볼까요, 고를 것(찬성·반대 + "고를 것 추가"), 취소 | 만들기.
- **일정 등록 시트**: 제목, 날짜, 시작 시간(**꼭 넣어야 저장됨**, 표시는 없음) · 종료 시간(선택), 장소(선택).

### 7-4. 원우 (원우수첩, 흰 바탕)
- 제목 "원우수첩 10기 ∨"(운영진만 기수를 바꿔 봄)
- 검색칸: "이름·회사·직책으로 찾기"
- 밑줄 탭: 전체 / 일반 원우 / 대학생 원우 (대학생 원우가 없는 기수는 "전체" 한 칸)
- 목록: 박스 없이 줄 사이 1px 회색 선
  - 왼쪽 사진칸 **136×76.5px**(16:9), 모서리 10px. 소개 영상이 있으면 영상 썸네일 + 오른쪽 아래 "▶ 영상" 검은 65% 딱지. 사진이 없으면 색 동그라미에 이름 두 글자
  - 가운데 "1. 홍길동" 굵게 + 회사 · 직책 주황(한 줄, 넘치면 ⋯)
  - 오른쪽 연필(누구나 그 원우 정보를 채워 줄 수 있음 — 채운 사람이 기록됨)
- **목록을 좌우로 밀면 옆 탭으로**: 손가락을 따라 움직이다가, 화면 폭 1/4(또는 60px)을 넘기거나 빠르게 튕기면 0.22초에 빠져나가고 반대편에서 새 목록이 들어옴. 끝 칸에서는 1/3만 따라옴.
- 원우를 누르면 상세 시트: 사진·영상, 1:1 채팅 · 전화 · 문자, "정보 수정하기"(연주황 칸 + 주황 연필).
- 아래 FAB "원우 추가하기"(명단에 아직 가입 안 한 원우를 미리 넣어 둠 → 가입하면 같은 이름끼리 이어짐).

### 7-5. 위원회 (회색 바탕)
- 제목 탭 "위원회 | 원우 소식"
- 위원회 카드(모서리 18px): 이름 20px 굵게 + 오른쪽 인원 알약(회색 13px) + 연주황 안내 상자
- 원우 소식: 사진 여러 장을 넘겨 보는 카드 + 글. 원우 소식에만 "소식 올리기".

### 7-6. 채팅 목록 (흰 바탕, 카카오톡식)
- 박스·선 없이 줄만. 줄 좌우 16px, 위아래 9px, 누르면 줄 전체가 옅은 회색.
- 사진 **56px 스쿼클**(2px 아래로). 기수 단체방은 회색 칸 + 두 사람 그림, 탈퇴한 원우는 회색 칸 + 한 사람 그림(같은 그림체).
- 이름 16px 굵게 + 굵은 회색 인원수("10기 단체 대화방 51") + 즐겨찾기 ★(주황) · 알림 끔 🔕(회색). 긴 이름은 ⋯
- 미리보기 14px ink-muted 두 줄까지, 시각 12px 흐림, 새 메시지는 10px 빨간 점(개수는 세지 않음)
- **순서**: 즐겨찾기한 방(최근 순) → 나머지(최근 순). 단체방도 즐겨찾기해야 맨 위.
- 상대가 탈퇴한 1:1 방: 이름 "탈퇴한 원우", 대화 기록은 남고 메시지는 못 보냄.

### 7-7. 대화방
- 제목 줄: 왼쪽 동그란 흰 `<`, 가운데 방 이름 + 인원수, 오른쪽 동그란 흰 **종**(이 방 알림 켜기/끄기 — 켜짐 채운 종, 꺼짐 선 종 + 사선) · **별**(즐겨찾기 — 켜짐 채운 별, 꺼짐 빈 별). 단추 44px, 1px 테두리.
- 날짜 구분: 가운데 13.5px 600 ink-muted, 위 16px · 아래 20px.
- 말풍선: 모서리 16px, 좌우 14px·위아래 8px, 15px 글씨, 줄바꿈 그대로
  - 내 말: 주황 + 흰 글씨, 오른쪽 아래 모서리만 덜 둥글게, 시각은 왼쪽
  - 남의 말: `fill` 회색, 왼쪽 아래 모서리만 덜 둥글게, 블록 첫 말에만 사진 32px
  - 고친 말: 끝에 11px "수정됨"
  - 내 말을 **꾸욱(0.45초) 누르면** 검은 작은 메뉴: 수정 / 전체에서 삭제
- 입력줄: 화면 아래 붙음, 흰 95% + 흐림. 회색 입력칸 + 44px 주황 동그라미 ↑ 보내기
  - **휴대폰**: 엔터는 줄바꿈, 보내기는 단추로만
  - **컴퓨터**: `. ! ? …`로 끝나고 엔터 → 보내기, 글자로 끝나면 줄바꿈, Shift+엔터는 늘 줄바꿈(한글 조합 중 엔터는 무시)
- 빈 방: 대화 칸 한가운데 말풍선 아이콘 + "아직 대화가 없어요" + "첫 메시지를 남겨보세요."
- 오른쪽으로 밀면 채팅 목록으로.

### 7-8. 자료 (흰 바탕)
- 제목 탭 **복습 영상 | 일정 | 파일**. **화면 어디서든 좌우로 밀면** 옆 칸으로.
- 복습 영상: 유튜브 채널 최신 영상 카드(16:9 썸네일 + 가운데 ▶ 64px 검은 55% 동그라미, 제목 15px, 날짜, "유튜브에서 보기 ↗"). 누르면 그 자리에서 재생.
- 일정: 기관 누리집 글 목록 카드.
- 파일: 박스 없는 줄 — 확장자 칸 48px(모서리 17.5px, "DOCX" 12px 굵게) + 파일 이름 16.5px 굵게(두 줄까지) + "올린 사람 · 크기 · 날짜" 13px 흐림 + 오른쪽 ⋯(받기 / 이름 바꾸기 / 삭제 — 뒤 둘은 올린 사람·운영진만, 삭제는 확인 창). 오른쪽 아래 FAB "+"로 올리기(한 개 10MB까지).

### 7-9. 알림 (흰 바탕)
- 날짜 머리글("오늘", "어제", "9월 21일 (월)") 15px 굵게 **주황**.
- 알림 줄: 박스 없음, 위아래 13px, 같은 날끼리 붙어 있음. 종류 아이콘 19px(달력·도장·재생·확성기) + 제목 15px 굵게 + 내용 13px 한 줄 + 오른쪽 꺾쇠.
- 열면 제목 줄 종의 빨간 점이 꺼짐.

### 7-10. 설정 (회색 바탕)
- 구역 제목 16px 회색 → 흰 알약 줄(높이 52px, 좌우 20px): 알림 받기 / 큰 글씨 / 다크 모드 — 오른쪽 스위치(켜짐 주황).
- 계정: 흰 상자에 "권한 · 로그인 계정"(14px).
- 로그아웃(주황 버튼, 확인 시트) · 탈퇴하기(밑줄 글씨, 확인 시트).
- **탈퇴**: 계정과 로그인 정보는 지우고, 원우수첩 칸은 명단으로 옮겨 남김(다른 원우가 계속 연락처를 볼 수 있게). 1:1 대화 기록도 남음.

### 7-11. 내 프로필
첫 프로필 화면과 같은 폼(흰 바탕·회색 칸). "저장하기"는 바뀐 게 있을 때만 켜짐. 오른쪽으로 밀어 뒤로.

| 오른쪽으로 밀기 | 대화방·설정·알림·내 프로필 등 하위 화면 | 화면이 손을 따라 밀리다 놓으면 이전 화면. 빈 여백에서 시작해도 됨 |
| 좌우로 밀기 | 원우 목록 | 옆 구분 탭으로(손 따라 움직이는 애니메이션) |
| 좌우로 밀기 | 자료 탭 전체 | 복습 영상 ↔ 일정 ↔ 파일 |
| 화면 끝 20px 밀기 | 탭 첫 화면 | **막음**(아이폰 사파리의 뒤로 가기가 탭을 끌어오지 않게) |
| 꾸욱 누르기 | 내 말풍선 | 수정 / 삭제 메뉴 |
| 끌어내리기 | 시트 손잡이 | 닫기 |
| 끌기·두 손가락 | 사진 편집 틀 | 위치 옮기기·확대 |

- 가로/세로 판단: 처음 10px 움직임으로 정하고, 세로면 그 손짓은 스크롤에 맡깁니다. 넘기는 기준은 60px 이상 + 가로가 세로의 1.5배 이상.
- 가로 손짓을 받는 상자에는 `touch-action: pan-y` (세로 스크롤은 브라우저, 가로는 앱).

## 9. 알림·데이터·권한 (기능 뼈대)

- **로그인**: 구글, 카카오(서버가 카카오 토큰을 확인해 Firebase 계정 발급), 휴대폰 문자 인증.
- **권한**: 원우(member) / 운영진(admin). 승인 전에는 아무것도 볼 수 없음. 로그인 없이 둘러보기는 보기만(올리기·수정 시 로그인 안내).
- **기수 분리**: 원우수첩·일정·단체 대화방·파일은 기수마다 따로. 복습 영상·기관 소식은 공통.
- **푸시 알림**: 웹 푸시. 새 채팅(방마다 끌 수 있음), 새 일정, 새 투표, 새 영상·소식. 받은 알림은 알림 화면에 날짜별로 쌓임.
- **저장소**: Firestore(모든 글·명단·대화), Cloudinary(사진·파일 — 브라우저에서 줄여서 올림: 프로필 정사각형, 행사 사진 긴 변 2560px).
- **무료로 운영**: 카드 없이 쓸 수 있는 한도 안에서 — 읽기 수를 줄이려고 오프라인 캐시, 읽음 표시는 묶어서 쓰기, 무거운 외부 글은 서버에서 받아 30분~1시간 캐시.

## 10. 작은 규칙들 (따라 만들 때 자주 걸리는 것)

1. **입력칸 글씨는 16px 이상.** 아이폰은 16px 미만 입력칸을 누르면 화면을 확대합니다.
2. 전역 `button { font-size: 16px }` 규칙을 둔다면, 작은 단추 글씨는 `text-[13px]!`처럼 **!(important)** 를 붙여야 먹습니다(레이어 밖 규칙이 이김).
3. 글씨만 옮기기: 버튼이 flex면 글씨를 `<span>`으로 감싸 `translate-y`. 입력칸은 transform이 칸째 움직이니 **위·아래 여백을 나눠** 옮깁니다.
4. 굵기를 "아주 조금" 바꿀 때: 700과 900 사이가 필요하면 `-webkit-text-stroke: 0.1~0.3px currentColor`로 테두리를 얹습니다.
5. 흰 바탕을 화면 끝까지: 본문 뒤에 `fixed inset-0 -z-10` 흰 층. 단, **이 층에는 손가락이 닿지 않습니다**(화면 틀 뒤). 빈 여백에서 손짓을 받아야 하면 상자 높이를 `calc(100dvh − 탭바 자리)`로 주거나 document에 손짓을 겁니다.
6. `transform`이 걸린 상자 안의 `position: fixed` 는 화면이 아니라 그 상자를 기준으로 섭니다 — 밀리는 화면 안에 떠 있는 요소를 두지 마세요.
7. 아이폰 상단 시계 줄 색은 **화면 맨 위에 붙은(sticky/fixed) 요소의 바탕색**을 따르고, 없으면 테마 색(`theme-color`)을 씁니다. 흰 화면이면 흰 제목 줄을 맨 위에 붙이세요.
8. 한글 IME: 엔터 처리 전 `event.nativeEvent.isComposing`을 꼭 확인하세요(마지막 글자 빠짐·두 번 전송 방지).
9. 삭제·탈퇴처럼 되돌릴 수 없는 것만 빨강. 빨강이 "조심"이라는 뜻을 유지하도록 다른 곳엔 쓰지 않습니다.
10. 값을 바꾸면 그 자리 주석에 **날짜와 이유**를 남깁니다. 1px 단위로 맞춘 값이 많아, 이유 없이 되돌리면 다시 어긋납니다.
