## 2. 앱 콘텐츠 (정책 → 앱 콘텐츠)
- 개인정보처리방침 URL: https://aegiaeta.web.app/privacy

  - 안내 문구 예: "앱을 열고 '휴대폰 번호로 시작하기'를 누릅니다. 번호 010-0000-0000 을 입력하고 인증번호 000000 을 입력하면 로그인됩니다. 별도 승인 없이 모든 기능을 쓸 수 있습니다."

- 콘텐츠 등급: 설문 시작 → 이메일 입력 → 카테고리 "소셜 미디어/커뮤니케이션 등" 선택

  - 사용자 간 소통/사용자 생성 콘텐츠: **예** (채팅·글·사진·댓글). **신고·차단 기능 있음**(글·사진·메시지·사람 단위 신고, 사용자 차단)
  - 위치 공유: 아니요 / 디지털 상품 구매: 아니요

## 3. 데이터 보안 (설문 답)
- 앱이 사용자 데이터를 수집하거나 공유하나요? **예**
- 모든 데이터는 전송 중 암호화? **예** (HTTPS)
- 사용자가 데이터 삭제를 요청할 수 있나요? **예** — 앱 안 탈퇴하기 + 위 삭제 URL
- 수집 항목 (모두 "수집됨 / 공유 안 함". 서비스 제공 업체(Firebase·Google, Cloudinary)에 맡기는 것은 구글 정의상 "공유"가 아닙니다)

| 구글 분류 | 항목 | 필수/선택 | 사용 목적 |
|---|---|---|---|
| 개인 정보 | 이름 | 필수 | 앱 기능, 계정 관리 |
| 개인 정보 | 이메일 주소 | 선택(구글·카카오 로그인 시) | 계정 관리 |
| 개인 정보 | 사용자 ID | 필수 | 앱 기능, 계정 관리 |
| 개인 정보 | 전화번호 | 필수에 가까움(원우수첩·휴대폰 로그인) | 앱 기능, 계정 관리 |
| 개인 정보 | 기타 정보(생일, 회사, 직책, 자기소개) | 선택 | 앱 기능(원우수첩, 생일 안내) |
| 사진 및 동영상 | 사진 | 선택 | 앱 기능(프로필·원우소식 앨범) |
| 메시지 | 기타 인앱 메시지(채팅) | 선택 | 앱 기능 |
| 앱 활동 | 기타 사용자 생성 콘텐츠(소식 글·댓글·투표·의견) | 선택 | 앱 기능 |
| 앱 활동 | 앱 상호작용(퀴즈 답안·점수) | 선택 | 앱 기능 |
| 기기 또는 기타 ID | 기기 또는 기타 ID(푸시 알림 토큰) | 선택(알림 켠 경우) | 앱 기능 |

- 위치·금융·건강·연락처(폰 주소록)·웹 기록·진단 정보: 수집 안 함
- 각 항목 "일시적으로만 처리됨?" → 아니요(저장됨)
- 처리 맡기는 곳: Google(Firebase 로그인·DB·알림·서버), Cloudinary(사진·파일 보관), Kakao(카카오 로그인 때)
