# 프로덕션 액세스(정식 출시) 신청 준비 노트 (2026-10-06 사용자 요청 (구글 플레이 출시 준비), 뉴웨이브앱 노트를 옮김)

핵심: 개인 개발자 계정은 정식 출시 전에 **비공개 테스트를 12명 이상, 14일 연속**으로 해야 합니다. 설치만이 아니라 **14일 동안 실제 기기에서 꾸준히(매일) 써야** 하고,
한 번 불합격하면 새 테스터로 14일을 다시 합니다. (구글 정책은 바뀌니 신청 때 Play Console 안내를 한 번 더 확인하세요.)

## 14일 동안 지킬 것
- [ ] 테스터 15~20명 확보(12명 아슬아슬하게 말고). 전원 구글 계정으로 옵트인 링크로 참여(스토어 일반 링크 설치는 카운트되지 않음).
- [ ] 테스터(원우)에게 "매일 한 번 앱을 열어 소식·채팅을 확인해 달라"고 부탁.
- [ ] 테스터가 앱을 지우지 않게 안내. 한 명이라도 빠지면 12명 아래로 떨어질 수 있음.
- [ ] 테스터 의견(버그·불편)을 모으는 창구 하나(카톡방 등) + Play Console 의견 이메일.
- [ ] 14일 중에 **업데이트를 1~2번 올림**(versionCode 2, 3…): 의견을 반영해 고쳤다는 근거가 신청서에 필요.
- [ ] 앱이 켜지자마자 꺼지는 문제가 없게 유지(비정상 종료는 불합격 사유).
- [ ] 외부(낯선) 테스터를 받을 때는 시험 계정이 실제 원우 정보를 볼 수 있다는 점에 유의(이 앱은 가입자 누구나 원우수첩을 읽음).

## 신청서에 쓸 수 있는 개선 사례
테스트하면서 실제로 고친 것을 여기 계속 적어 둘 것(폰 테스트에서 겪은 문제와 해결).

## 신청서 3단계 답안 초안 (숫자·사실은 실제로 맞게 고칠 것)
**1단계 — 테스트 진행**: 도산아카데미 애기애타 10기 원우 중 안드로이드 사용자로 모집. 사용한 기능: 로그인(구글·카카오·휴대폰), 원우소식, 원우수첩, 채팅, 투표, 일정, 신고·차단, 알림. 의견은 실제로 받은 것을 정리.
**2단계 — 앱 정보**: 대상은 도산아카데미 애기애타 10기 원우. 가치: 소식·수첩·채팅·일정을 한 앱에서 보고 원우 간 연결을 돕는다. 예상 설치는 원우 수 기준으로 사실대로.
**3단계 — 프로덕션 준비**: 비공개 테스트에서 고친 점, 신고·차단·삭제 안내 페이지, 개인정보 처리방침 준비 완료, 심사용 시험 계정 제공.

## 불합격 방지 점검
- [ ] "웹사이트를 그냥 감싼 앱"으로 보이지 않게: 푸시 알림, 앱 전용 로그인(구글·휴대폰·카카오), 신고·차단 같은 앱 기능을 설명·신청서에 분명히 적기(구글 최소 기능 정책).
- [ ] 개인정보 처리방침·삭제 안내 주소(aegiaeta.web.app/privacy, /account-deletion)가 열리는지 주기적으로 확인.
- [ ] 심사용 시험 계정(010-0000-0000 / 000000)이 계속 로그인되는지 확인. 심사 끝나면 삭제(`node scripts/play-review-account.mjs delete`).
